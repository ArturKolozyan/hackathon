# Ассистент Кип

Кип — имя и маскот ассистента, только в веб-версии: в панели и в системном промпте («Вы — Кип, помощник в rekeeper»). Тон дружелюбный, но деловой, на «вы».

Маскот: `frontend/public/brand/kip.svg` (исходник), компонент `frontend/src/components/Kip.tsx`, состояния `idle` (дышит со сжатием, покачивается, моргает раз в 2,5–5 с, дёргает ушами на 14°, машет хвостом), `thinking` (наклоняет голову, водит глазами, хвост быстрее), `talking` (рот и подпрыгивание), `happy` (прыжок со сжатием после «Подтвердить»). При `prefers-reduced-motion` анимаций нет. Цвета фиксированные: тело #E97C35, хвост #C66A2D, глаза белые; на оранжевую подложку Кипа не ставим.

В Telegram Кипа нет: бот присылает уведомления и принимает «Оплачено», на любой другой текст отвечает, что Кип работает в веб-версии, и даёт ссылку (`APP_PUBLIC_URL`).

Чат в вебе — панель на каждой странице кабинета (Кип справа снизу). Отдельного пункта меню нет: `/assistant` открывает ту же панель. Процесс — контейнер `assistant` (`backend/app/assistant_main.py`). Веб ходит в него тем же cookie или bearer. Бот ходит по HTTP с короткой сессией этого пользователя. Запись идёт через `perform` / те же функции, что REST, и только после «Подтвердить».

Как отвечает Кип:

- **Команды** без модели: «отметь X оплаченным», «верни X в неоплаченные», «создай / измени / архивируй платёж …», «очисти чат», «что умеешь». Регулярки только для них.
- **Всё остальное** — GigaChat с инструментами (`backend/app/assistant/agent.py`). За ход до 5 вызовов (GigaChat возвращает один `function_call` за ответ), результат каждого уходит модели сообщением `role: function` (компактный JSON до ~2 КБ), бюджет хода ~25 с, temperature 0.1. Модель отвечает на каждый подвопрос, цифры только из результатов.
- **Инструменты** (`tools.py`): `query_operations` — выборка и агрегаты по счетам (период или даты, срок или дата оплаты, статус, отделы, валюта, ответственный, платёж; группировка; count/sum/avg/min/max по каждой валюте; рубли по ЦБ; строки; пакет `queries` на несколько подвопросов), `get_payment`, `get_budget`, `product_help` (справка по текущему интерфейсу, `guide.py`), для админа и владельца `list_people` и `get_audit`. Изменения — `propose_*`: карточка, запись только после «Подтвердить».
- **Доступ**: отделы из `department_access` (владелец — все, остальные — свои). Запрос чужого отдела возвращает `denied`, Кип говорит об этом прямо. Модель видит только инструменты своей роли, `tools.call` проверяет роль ещё раз.
- **Контекст**: последние 8 сообщений, ответы без таблиц — работают «а в рублях?», «а у Маркетинга?». В системном промпте дата, день недели и время в часовом поясе организации, имя, роль и отделы человека.
- **Подсказки**: под каждым ответом ровно три вопроса (`suggestions` в ответе API). Модель пишет их строкой `>>> … | … | …`, бэкенд вырезает, чистит (до 40 знаков, по роли) и добивает до трёх по роли и инструментам (`suggestions.py`). Стартовые — `GET /api/v1/assistant/suggestions`.
- **Если GigaChat недоступен**: есть данные инструмента — короткий ответ по ним; «что просрочено», «что на неделе» — ответ из базы; остальное — вежливая ошибка.

Голос в вебе: зажать микрофон или нажать (клик-режим), до 25 секунд. Текст попадает в поле, его можно поправить и только потом отправить.

## Как проверить руками

1. Войти на https://rekeeper.ru, открыть Кипа: первым сообщением он здоровается, под ним три подсказки.
2. «Какие операции были за прошлый месяц, сколько просрочек, сколько каких и на какую сумму, и средний чек» — четыре блока ответа с цифрами из базы.
3. «а в рублях?» — тот же период, итог по курсу ЦБ.
4. Участником: «сколько просрочено в Маркетинге?» (если он не в Маркетинге) — «нет доступа».
5. «Создай платёж „Домен“ 1200 рублей каждое 20 число, ответственный Иван» — карточка, в шаблонах пусто до «Подтвердить».
6. «Как приложить чек?», «Как настроить вебхук?», «Как сменить пароль?» — справка по текущим экранам.

Пустой `GIGACHAT_AUTH_KEY` или пустой `COMPOSE_PROFILES` — контейнер `assistant` не создаётся, кнопки чата нет. `DELETE /api/v1/assistant/messages` (или «очисти чат») очищает историю этого человека в текущем отделе и отменяет висящие карточки.

Регресс: `backend/tests/test_assistant_agent.py` гоняет цикл на записанных ответах модели (`tests/kip_fake.py`): вопрос из четырёх частей, отказ по чужому отделу, рубли, пакет, лимит шагов, падение модели, подсказки.

## Env

| Переменная | Смысл |
|------------|--------|
| `GIGACHAT_AUTH_KEY` | Ключ Basic для OAuth, без слова Basic. Уже на VPS. |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | По умолчанию `GigaChat-2-Max` |
| `GIGACHAT_FALLBACK_MODEL` | `GigaChat-2-Pro`, если основная модель не принята |
| `YANDEX_SPEECHKIT_API_KEY` | Api-Key SpeechKit. Уже на VPS. |
| `YANDEX_FOLDER_ID` | Каталог для `stt:recognize`. Уже на VPS. |

Сертификат Минцифры лежит в `backend/certs/russian_trusted_root_ca.pem` и подключается к проверке TLS. `verify=False` нет. Токен GigaChat кэшируется и обновляется раньше, чем истекут 30 минут.
