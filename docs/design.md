# Design — Invoice Keeper × AEZA

[AGENTS.md](../AGENTS.md) · [product](product.md)

**Решение:** визуальный язык как у AEZA (узнаваемость для жюри), без копипаста их лендинга 1:1. Источники: aeza.net (маркетинг) + my.aeza.ru (кабинет). Hex частично из HTML, частично приближение со скринов.

## Настроение

Светло, воздушно, мало шума. Страница `#F5F5F5`, поверхности белые, карточки без жирных бордеров и теней. Тёмный режим не дефолт (тёмная карточка — только акцент).

## Токены

```css
--bg: #F5F5F5;
--surface: #FFFFFF;
--card: #F3F3F3;
--accent: #16B9CF;       /* основной CTA / чипы */
--accent-tint: #DDFBFF;
--accent-soft: #E6F7FA;
--ink: #111111;
--ink-on-dark: #FFFFFF;
--dark-card: #1E1E1E;
--muted: #616161;
--disabled: #A0A0A0;
--success: #2CC04D;      /* «работает» / оплачено вовремя */
--warn: #F28C00;         /* кабинет: бейджи/ссылки; у нас — «скоро» / внимание */
--danger: /* просрочено — красный в духе кабинета, уточнить на UI */ #E5484D;

font-family: Inter, system-ui, sans-serif;
/* weights: 400 / 500 / 600 / 700 */
```

**Радиусы:** карточки 16–20px · кнопки 10–12px или pill 999 · модалки ~20px.  
**Сетка:** шаг ~8px, padding карточки 14–16, gap 8–10.  
**Тени:** почти нет (только модалки/тосты).

## Лого / бренд

Wordmark AEZA не копируем как «наш логотип продукта». Можно: «в духе AEZA» + наш wordmark Invoice Keeper, мелкий дисклеймер «для хакатона AEZA». Акцент cyan — да.

## Паттерны под наш инбокс

| Элемент | Как в духе AEZA |
|---------|------------------|
| Фон приложения | `--bg`, контент на `--surface` |
| Инбокс-строка | `--card`, без бордера, radius 16 |
| CTA «Оплатить» / primary | pill `--accent`, текст белый |
| Secondary / вход | тёмная pill `#1A1A1A` или серая `#EDEDED` |
| Просрочено | danger + верх инбокса |
| Скоро | `--warn` |
| Оплачено | `--success` |
| Модалка | белая, dim overlay, radius 20 |
| Таблицы | серые заголовки, без зебры и тяжёлых линий |
| Сайдбар (если будет) | светлый, мелкий muted-текст, как кабинет |

## Do / Don’t

**Do:** один cyan-акцент на поверхность · Inter · много воздуха · инбокс как очередь, не Excel.  
**Don’t:** тяжёлые тени/бордеры · радуга акцентов · тёмный UI по умолчанию · копировать 3D-глобус героя на каждый экран.

## Для фронта (агенту)

Завести CSS variables / theme в одном месте (`web/src/styles/tokens.css` или аналог). Главный экран = инбокс в этих токенах. Скрин-референсы можно положить в `docs/design-refs/` позже.
