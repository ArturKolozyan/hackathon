# Design — Invoice Keeper × AEZA

[AGENTS.md](../AGENTS.md) · [product](product.md)

**Решение (Artur, 2026-10-23):** визуальный язык продукта = тёмный личный кабинет [my.aeza.ru](https://my.aeza.ru). Узнаваемость для жюри — из кабинета. [aeza.net](https://aeza.net) — маркетинг; в дефолт UI и в кнопки его не берём, 1:1 не копируем. Hex ниже сняты со скринов кабинета (плюс wiki как соседний тёмный экран, не shell продукта).

## Настроение

Почти чёрный фон, контент в charcoal-панели с крупным радиусом. Мало шума и теней: поверхности различаются яркостью, не обводкой. Акцент кабинета — оранжевый `#FF7A00` (бейдж, «+», полоска метрики). Главная кнопка светлая, вторичная тёмная. Статус «работает» — зелёная точка.

Wiki (`wiki.aeza.ru`) тоже тёмная, но это база знаний: сайдбар `#191919`, фон `#121212`, синяя иконка справки `#2878F8`. Shell продукта с wiki не смешиваем.

## Токены

```css
--bg: #000000;                 /* сайдбар и поле вокруг панели */
--surface: #131313;            /* контент-панель */
--card: #1F1F1F;               /* карточка, метрика, круг empty-иконки, модалка */
--nav-active: #1A1A1A;         /* soft-pill пункта сайдбара */
--ink: #FFFFFF;
--muted: #A3A3A3;              /* подпись empty ~#B0B0B0, колонки таблицы ~#9A9A9A */
--accent: #FF7A00;             /* бейдж, «+», полоска, «скоро» */
--warn: #FF7A00;               /* тот же amber: отдельного жёлтого на скринах нет */
--accent-soft: rgba(255, 122, 0, 0.16);
--success: #2CC04D;            /* полоска метрики / «оплачено» */
--success-dot: #73DA39;        /* точка «работает» */
--danger: #FF4D4F;             /* просрочено; красного на этих скринах нет */
--danger-soft: rgba(255, 77, 79, 0.16);
--btn-primary: #F2F2F2;
--btn-primary-ink: #131313;
--btn-secondary: #2B2B2B;
--btn-secondary-ink: #E3E3E3;
--landing-cyan: #16B9CF;       /* только aeza.net; в CTA кабинета не ставить */

font-family: Inter, system-ui, sans-serif;
/* weights: 400 / 500 / 600 / 700 */
```

**Радиусы:** панель ≈26px · кнопки ≈16px (высота на скрине ~64px, не капсула) · карточки 16–20px · модалка 20–26px · active в сайдбаре — мягкая pill.  
**Сетка:** шаг ~8px, padding карточки 14–16, gap 8–10. Полоска метрики ≈3px.  
**Тени:** почти нет. Край карточки — ступенька `#131313` → `#1F1F1F`, без жирного бордера.  
**Иконки:** тонкий outline, как в сайдбаре кабинета.

## Лого / бренд

Наш wordmark — Invoice Keeper. Мелкий дисклеймер «для хакатона AEZA». Wordmark AEZA и плитки `a é z a` с wiki не используем как логотип продукта. Оранжевый акцент — да. Cyan лендинга — нет.

## Паттерны под наш инбокс

Инбокс остаётся очередью: просрочено → скоро → остальное. Закрытый период уходит из очереди. Таблица кабинета («Мои услуги») — ориентир для тихих списков админки, не замена очереди.

| Элемент | Как в кабинете |
|---------|----------------|
| Shell | `--bg` + панель `--surface`, радиус ≈26. Сайдбар слева |
| Сайдбар | сверху кто вошёл; outline-иконки; active = `--nav-active`; снизу приподнятая строка `#131313` и «+» цвета `--accent` (наша подпись, не «Добавить услугу») |
| Бейдж-счётчик | как «6+»: фон `--accent`, если есть число. Не декор |
| Строка инбокса | карточка `--card` на панели. Статус — точка или полоска 3px слева, не заливка строки |
| Просрочено | `--danger` / `--danger-soft`, верх очереди |
| Скоро | `--warn` (`#FF7A00`) |
| Оплачено | точка `--success-dot` или полоска `--success`; в истории, не в очереди |
| Остальное | без акцентной полоски, текст `--ink` / `--muted` |
| Primary CTA | `--btn-primary`, текст `--btn-primary-ink`. «Оплатить» и главное действие empty |
| Secondary | `--btn-secondary`, текст `--btn-secondary-ink` |
| Empty | outline-иконка в круге `--card` + заголовок `--ink` + подпись `--muted` + две кнопки (светлая, затем тёмная) |
| Метрики | карточка `--card`, слева полоска 3px: `--success` или `--accent` |
| Таблицы админки | заголовки `--muted`, значения `--ink`, без зебры и тяжёлых линий |
| Модалка | `--card` на dim `rgba(0,0,0,.6)`, радиус 20–26, те же две кнопки. На скринах модалки не было |

## Do / Don’t

**Do:** тёмный кабинет по умолчанию · один оранжевый `#FF7A00` на бейдж, «+» и «скоро» · светлая primary · Inter · инбокс как очередь · статус точкой или тонкой полоской.

**Don’t:** светлая тема и `--landing-cyan` как дефолт · оранжевая заливка каждой кнопки · зебра, тяжёлые бордеры и тени · радуга акцентов · копировать 3D-глобус лендинга и wordmark AEZA · превращать инбокс в Excel.

## Для фронта (агенту)

Сейчас `frontend/src/styles.css` — светлая бумага: фон `#efeae1` (`--paper`), шрифт Manrope. Целевое состояние — токены этого файла, главный экран = инбокс. CSS в этом заходе не меняем: отдельный UI-pass после merge docs. Переменные собрать в одном месте (`frontend/src/styles.css` или рядом). Скрины в `docs/design-refs/` не кладём.
